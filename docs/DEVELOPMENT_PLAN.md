## 构建阶段：120 分钟

### A. 项目、数据和身份 — 25 分钟

- 建立 Vue 3/Vite/Element Plus 前端及 FastAPI/SQLAlchemy 后端。
- 建表、外键和唯一约束，配置 SQLite WAL、foreign_keys、busy_timeout。
- 可重复执行的 seed：Sydney 与 Perth 两个租户，各有管理员、课程、报名和证书。
- 登录、退出、当前身份和统一租户依赖；开发代理、cookie 和写请求来源检查。
- 建立本地启动脚本；自动建表和 seed，首次依赖安装及所需 Python/Node 版本明确记录。
- 验收：可启动、可登录两个账号，身份与租户正确，重复启动无重复 seed。
- 提交：项目骨架、数据模型、seed 和身份。

### B. 列表和详情 — 25 分钟

- 共享查询构造函数、搜索、课程/状态筛选、分页和排序白名单。
- 列表和详情 API，所有访问限定当前租户。
- 登录页和主页面，列表三种状态、详情抽屉、搜索防抖与过期响应保护。
- 撤销确认，状态与审计一起提交，重复撤销安全。
- 验收：搜索、翻页、排序、详情和撤销可操作；跨租户 id 返回 404。
- 提交：证书浏览和撤销流程。

### C. 批量发证和事务测试 — 40 分钟

- 请求 key 的生成、暂存、原 key 重试及冲突处理。
- 显式写事务，证书唯一约束，逐学员 savepoint，证书与审计原子写入。
- 持久化批次响应，整体错误回滚，锁超时可重试。
- 发证弹窗、不定进度提示、逐学员结果、完成后的数据刷新。
- 测试同 key 重放、不同 key 重试、真实独立连接并发及审计失败回滚。
- 验收：不重复发证或审计；响应丢失后重试可恢复原结果。
- 提交：幂等批量发证及相关测试。

### D. CSV 和剩余关键验证 — 30 分钟

- 复用列表筛选，导出全部匹配数据，标准 CSV 编码和文本安全处理。
- 分批读取、流式输出、明确读事务及连接生命周期。
- 统一租户时区，浏览器下载。
- 测试跨租户导出、超过一页、特殊字符、空结果、时间转换一致性。
- 检查网络错误、401、空列表和按钮状态。
- 验收：导出结果与筛选匹配，行数完整，未在应用内一次性加载全部记录。
- 提交：CSV、时区及关键边界验证。

## 自检演示顺序：10 分钟

1. 使用文档中的启动步骤运行，登录 Sydney 管理员。
2. 搜索学员及编号，翻页和排序，查看详情及租户时区。
3. 对已结束课程批量发证，观察处理中状态和逐学员结果。
4. 再次发证验证跳过；使用自动化测试证明同 key 重放和并发保护。
5. 取消一次撤销，再确认撤销，检查列表和详情状态。
6. 带筛选导出 CSV，核对跨页记录及时间。
7. 切换 Perth 管理员，确认没有旧租户数据残留；验证跨租户资源访问被拒绝。

## 测试策略

- 后端使用 pytest；涉及事务和并发时使用临时文件 SQLite，确保独立连接，不用单连接内存库掩盖问题。
- 并发断言最终只有一张证书和一条签发审计；同 key 返回相同结果。
- 注入审计失败验证原子性；批次级错误验证整体回滚；不只测试成功路径。
- 隔离覆盖列表、详情、课程、发证、撤销、导出。
- 时区使用固定时间样本，覆盖冬夏时间及 UTC/本地跨日；核对详情与 CSV。
- CSV 测试匹配行数、超过分页大小、文本转义、空结果；不以“成功下载”代替内容验证。
- 前端以浏览器端到端自检为主，优先检查状态和完整流程，不扩展通用组件测试。
